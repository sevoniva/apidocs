## Web / PWA

<Steps>
  <Step title="打开网页">
    打开网页版
  </Step>
  <Step title="进入设置">
    点击左下角设置图标
  </Step>
  <Step title="填写参数">
    - **接口地址**：`https://token.jinruntech.com/v1`
    - **API Key**：填入你的 `sk-` 密钥
    - **自定义模型**：输入模型 ID，如 `gpt-4o,deepseek-chat`
  </Step>
  <Step title="保存使用">
    点击保存
  </Step>
</Steps>

## iOS / Android

App Store 或应用市场搜索 **NextChat** 下载，配置方式与 Web 版一致。
