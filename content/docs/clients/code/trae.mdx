## 配置步骤

<Steps>
  <Step title="下载安装">
    从 [TRAE 官网](https://trae.ai) 下载安装
  </Step>
  <Step title="进入模型设置">
    打开 TRAE 面板，点击右上角设置 → 左侧菜单选择 Models → 点击 "Add Custom model here"
  </Step>
  <Step title="选择提供商">
    Provider 选择 "OpenAI"，点击 "Custom Model ID to use a non-listed model"
  </Step>
  <Step title="填写参数">
    - **Model ID**：`gpt-4o`
    - **API Key**：你的 `sk-` 密钥
    - **Custom Request URL**：`https://token.jinruntech.com/v1/chat/completions`

    注意填完整的 API 端点 URL，不是基础 URL。留空则使用默认地址。
  </Step>
  <Step title="开始使用">
    添加模型后，在对话面板关闭 Auto Mode，模型下拉列表选择添加的自定义模型
  </Step>
</Steps>
