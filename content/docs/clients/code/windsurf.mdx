## 配置步骤

<Steps>
  <Step title="打开设置">
    打开 Windsurf → 设置 → AI
  </Step>
  <Step title="选择 BYOK">
    选择 **Bring Your Own Key** 或 **Custom**
  </Step>
  <Step title="选择提供商">
    Provider 选择 **OpenAI Compatible**
  </Step>
  <Step title="填写参数">
    - **API Key**：你的 `sk-` 密钥
    - **Base URL**：`https://token.jinruntech.com/v1`
    - **Model**：`gpt-4o`
  </Step>
  <Step title="保存">
    保存
  </Step>
</Steps>
