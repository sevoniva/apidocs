## 配置步骤

<Steps>
  <Step title="安装插件">
    打开 VS Code，在扩展市场搜索 **Roo Code**，安装
  </Step>
  <Step title="打开面板">
    打开 Roo Code 面板
  </Step>
  <Step title="配置 API">
    - **API Provider**：选择 `OpenAI Compatible`
    - **Base URL**：`https://token.jinruntech.com/v1`
    - **API Key**：你的 `sk-` 密钥
    - **Model**：`gpt-4o`
  </Step>
  <Step title="调整选项">
    可选调整：
    - **Context Window Size**：`1048576`
    - 取消勾选 **Image Support**
  </Step>
  <Step title="开始使用">
    保存，在输入框输入需求即可使用
  </Step>
</Steps>
