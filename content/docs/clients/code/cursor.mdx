## 配置步骤

<Steps>
  <Step title="打开设置">
    打开 Cursor，点击右上角设置 → Models
  </Step>
  <Step title="选择自定义 Key">
    找到 Custom API Key 或 Override API Key
  </Step>
  <Step title="选择提供商">
    选择 `OpenAI API Key`
  </Step>
  <Step title="填写参数">
    - **API Key**：你的 `sk-` 密钥
    - **Base URL**：`https://token.jinruntech.com/v1`
  </Step>
  <Step title="保存">
    保存
  </Step>
</Steps>
