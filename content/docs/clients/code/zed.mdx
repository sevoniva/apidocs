## 配置步骤

<Steps>
  <Step title="下载安装">
    从 [Zed 官网](https://zed.dev) 下载安装
  </Step>
  <Step title="打开智能体面板">
    打开 Zed，进入智能体面板
  </Step>
  <Step title="添加供应商">
    添加供应商，填写：
    - **Provider Name**：自定义名称
    - **API URL**：`https://token.jinruntech.com/v1`
    - **API Key**：你的 `sk-` 密钥
    - **Model Name**：`gpt-4o`
  </Step>
  <Step title="选择模型">
    保存后，LLM Providers 列表中会出现添加的供应商，选择模型即可开始使用
  </Step>
</Steps>
