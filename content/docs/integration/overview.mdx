## 通用配置

<Steps>
  <Step title="找到 API 设置">
    打开客户端设置，找到 "自定义 OpenAI API" 或 "自定义 Base URL"
  </Step>
  <Step title="替换 Base URL">
    将地址替换为：`https://token.jinruntech.com/v1`
  </Step>
  <Step title="填入 API Key">
    粘贴你的 `sk-` 开头密钥
  </Step>
  <Step title="选择模型">
    选择或手动输入模型 ID，如 `gpt-4o`、`deepseek-chat`
  </Step>
</Steps>
