## 原理

默认情况下 API 等生成完成后再一次性返回。开启流式输出后，每生成一个 token 立即返回，客户端可实时展示，减少等待时间。

OpenAI 格式加 `stream: true`，Anthropic 格式使用 `client.messages.stream()`。

## SSE 格式

流式响应为 SSE（Server-Sent Events）格式：

```
data: {"id":"...","choices":[{"delta":{"content":"H"}}]}

data: {"id":"...","choices":[{"delta":{"content":"e"}}]}

data: [DONE]
```

每行以 `data:` 开头，空行分隔，最后以 `data: [DONE]` 结束。

## 前端接收示例

```javascript
const response = await fetch('https://token.jinruntech.com/v1/chat/completions', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': 'Bearer 你的sk-密钥'
  },
  body: JSON.stringify({
    model: 'gpt-4o',
    messages: [{role: 'user', content: 'Hello'}],
    stream: true
  })
});

const reader = response.body.getReader();
const decoder = new TextDecoder();

while (true) {
  const { done, value } = await reader.read();
  if (done) break;
  const chunk = decoder.decode(value);
  // 解析 SSE 数据行
}
```

<Callout type="info">
  SSE 流中每个 `data:` 行都是一段 JSON，需要逐行解析。最后收到 `data: [DONE]` 表示流结束。
</Callout>
