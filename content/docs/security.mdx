## 建议做法

<Callout type="info">
  不同场景创建不同 Key，如 `cherry-studio`、`cline-dev`。单 Key 泄露只影响一处。
</Callout>

**代码中使用环境变量**：

```python
import os

client = OpenAI(
    api_key=os.environ.get("OPENAI_API_KEY"),
    base_url="https://token.jinruntech.com/v1"
)
```

运行前设置环境变量：

```bash
export OPENAI_API_KEY="你的sk-密钥"
python script.py
```

**定期更换**：长期使用后或怀疑泄露时，删除旧 Key，创建新 Key 并更新到各客户端。

**异常处理**：发现额度异常消耗时，到 [控制台](https://token.jinruntech.com) 查看消费记录，确认是哪个 Key，立即删除并重建。
